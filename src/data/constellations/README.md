# 별자리 자료

공식 88개 별자리를 하나씩 갖는 도감입니다. 황도 12궁이 먼저 나오며, 나머지는 한글 이름순입니다. 별자리마다 별을 선택해 연결하는 방식은 문화·성도에 따라 달라집니다. 이 프로젝트는 d3-celestial의 선 데이터를 기반으로 한 감상용 지도입니다.

- `catalogue.json`: 실제 적경·적위 참조, 화면용 좌표, 중복 없는 연결선, 계절 분류, 삽화 매핑.
- `stories.js`: 한국어 설명과 생일 구간. 12궁 날짜는 일반적인 생일 분류이며 실제 태양 통과일이나 관측 가능 날짜를 의미하지 않습니다.
- `sources.json`, `DATA-LICENSE.txt`: 자료 출처와 BSD 3-Clause 원문. 빌드 배포에도 `public/art/constellations/DATA-LICENSE.txt`가 포함됩니다.
- `../art.js`: 삽화의 atlas 격자·타일 또는 개별 PNG를 해석하는 공통 함수.

`npm run catalogue:import`로 자료를 다시 가져올 수 있습니다. 다운로드 캐시는 `tmp/catalogue`에 보관합니다. 소스 URL의 최신 버전은 달라질 수 있으므로 변경된 JSON과 그림을 검토하고 함께 보관하세요. 생성한 `public/art/zodiac-atlas.png`는 저장소에 포함된 자산을 사용합니다. 실행 중 외부 천문 서비스에 접속하지 않습니다.

투영 시 평균 구면 방향을 중심으로 방위정거 투영을 적용해 적경 0도 경계에서도 별이 찢어지지 않게 합니다. 점을 중복 제거한 뒤 화면 좌표에서 최소 0.185 간격으로 벌립니다. 원본 적경·적위는 `skyCoordinates`에 남기며, 기존 양자리·카시오페아·오리온·북두칠성의 수동 좌표는 `shapes.js`에서 우선합니다. 삽화는 별 모양 뒤에 배치한 장식이며 과학적으로 보정된 성도는 아닙니다.

Serpens는 자료의 두 영역을 합쳐 88개 중 한 항목으로 저장하고 원래의 분리된 연결 구조를 유지합니다. 별이 2~3개뿐인 항목도 그대로 표현합니다. 자유 인식에서 이들을 억지로 구분하지 않으며, 지정한 템플릿의 복원에는 2개부터 허용합니다.

Three.js는 선택한 그림만 읽고 최대 12개 텍스처를 유지합니다. 빠르게 다른 별자리를 골라도 늦게 도착한 이전 그림이 덮어쓰지 않습니다. 좌표·연결·자산 무결성은 `npm test`, 88개 실제 선택 및 모바일 동작은 개발 서버 실행 후 `npm run test:catalogue`로 검증합니다.
