Constellation : 별로 그리는 사람

부제 — 당신의 움직임은 사라지지 않는다

D-MIX 전시회 출품작AI × 인터랙티브 미디어아트기획서 v1.0

1. 작품 제작 목적 (공식)

본 작품은 관람객의 움직임과 제스처를 AI가 실시간으로 해석하여 하나의 생성형 예술 작품으로 재구성하는 인터랙티브 미디어아트이다. 관람객은 화면 속 별을 직접 움직이고 연결할 수 있으며, 일정 시간이 지나면 AI가 지금까지 축적된 별의 흐름과 움직임을 분석하여 새로운 형태의 작품으로 재탄생시킨다. 이를 통해 사람의 순간적인 행동이 아름다운 디지털 흔적으로 남는 경험을 제공하고, AI를 단순 자동화 기술이 아닌 예술적 해석 도구로 표현하고자 한다.

2. 작품 내용 (공식)

관람객이 전시 공간 앞에 서면 손동작으로 화면 속 별을 잡아 이동시키거나 새로운 별을 생성할 수 있다. AI는 실시간으로 다음 요소를 분석한다.
  • 손의 이동 경로
  • 머문 시간
  • 별의 분포
  • 관람객 간 상호작용
  • 전체 공간 균형
일정 시간이 지나면 AI가 현재 공간을 해석하여 작품을 생성한다.
관람객 행동AI 해석 결과
포즈를 취하면별들이 모여 사람의 윤곽을 추상적으로 표현
손을 펼치면꽃처럼 퍼지는 별자리 생성
여러 사람이 함께 있으면서로 연결된 은하 구조 형성
움직임이 적으면고요한 성운 생성
생성된 작품은 지속적으로 변화하며 전시 종료 시 하나의 거대한 별자리 아카이브로 완성된다.

3. 활용방안 및 기대효과 (공식)

  • AI 기반 생성 예술 체험 제공
  • 관람객 참여형 전시 구현
  • 기술과 감성을 연결하는 디지털 콘텐츠 제작
  • 결과물 기록 및 전시 자산 활용 가능

아래부터는 위 공식 문구를 실제로 구현하기 위한 상세 기획입니다.

4. 관람객 경험 흐름

① 원경 (5m+) — 아무도 없어도 성운·별 필드가 천천히 떠다니며 은은히 명멸. 낮은 앰비언트 사운드만. "저 화면 뭔가 살아있다"는 첫 호기심 유발.
② 접근 (2~5m) — 존재 감지 시 별들이 그 사람 방향으로 서서히 모여듦. 화면 구석에 AI INTERPRETING… 텍스트 페이드인.
③ 체험 (~1.5m, 트래킹 존) — 손짓으로 별 생성·이동·연결. 하단에 아주 작은 손모양 픽토그램으로만 조작법 암시(텍스트 설명 없음).
④ 클라이맥스 — 포즈를 2~3초 유지하면 누적된 별들이 그 사람의 실루엣으로 재배열. 셔터음 + 화면 플래시 — 사진 촬영 유도 타이밍.
⑤ 퇴장 — 만든 별이 사라지지 않고 배경 필드로 서서히 흡수 → 다음 방문객의 밑그림이 됨 ("당신의 움직임은 사라지지 않는다"가 시각적으로 증명되는 순간).

5. 화면 구성 (UI 없이, 예술 중심)

레이어내용
배경 (원경 성운)파티클 수천 개, 파를린 노이즈로 느리게 흐름. 남색·보라·금색 톤. 사람이 없어도 항상 살아있음
누적 (아카이브)오늘 쌓인 모든 별. 최근 것일수록 밝고, 오래될수록 배경에 서서히 스며듦 — 시간의 흐름을 유일하게 보여주는 장치
전경 (현재 상호작용)지금 트래킹 중인 손에 직접 반응하는 밝은 파티클

텍스트는 AI INTERPRETING… → ANALYZING MOVEMENT → GENERATING CONSTELLATION 로그 하나만 허용. 버튼·점수·메뉴 없음.

6. AI의 실제 역할

구분담당기술
진짜 AI (인식)다인원 포즈 추정, 손 제스처 인식, 실루엣 분리TensorFlow.js MoveNet MultiPose, MediaPipe Hand/SelfieSegmentation
생성 알고리즘 (해석·번역)별을 실루엣으로 끌어당기는 힘, 노이즈로 유기적 형태 부여, 다인원 거리·속도 유사도로 연결선/은하 구조 생성Three.js 파티클 시스템 + 힘장(force field) 커스텀 로직

→ "AI가 인식한 몸짓을 생성 알고리즘이 예술로 번역한다"고 설명하는 것이 정확하고, 심사 질의응답에서도 정직하게 답할 수 있는 표현입니다.

7. 구현 기술 — 단계별

단계구성
쉬운 버전Three.js(렌더링) + TensorFlow.js MoveNet MultiPose(다인원 포즈) + MediaPipe Hand Landmarker(제스처). 노트북 1대 + 웹캠 1대, 서버 불필요, HTML 단일 파일
중간 버전+ MediaPipe SelfieSegmentation(포즈→실루엣 초상 기능) · Teachable Machine으로 제스처 직접 학습 · Tone.js 반응형 사운드
고급 버전+ 뎁스 카메라(Azure Kinect/Orbbec)로 조명에 강건한 다인원 3D 추적 · GPU 컴퓨트 셰이더로 파티클 대규모 확장 · 커스텀 학습 생성모델

권장: 쉬운 버전을 끝까지 완성도 있게 만들고 SelfieSegmentation만 추가 — 일정 대비 가장 안전하면서 핵심 연출을 전부 구현 가능.

8. 차별점 (심사 대응)

  • 원본 영상 비노출 — 좌표만 추출하고 카메라 원본은 화면에 절대 띄우지 않음. 개인정보 보호 + 예술적 추상화를 동시에 확보
  • 리셋되지 않는 하루짜리 공동 작품 — 데모가 아니라 지속형 제너레이티브 아트로 포지셔닝
  • 다인원 관계성 분석 — 대부분의 유사 작품이 단독 포즈 추적에 그치는 것과 달리, 관람객 간 거리·속도 유사도로 은하 구조를 생성하는 것은 기술적으로 실제 어려운 지점 → 심사 시 직접 강조
  • AI 투명성 — 부스 옆 QR/패널로 "실제 AI가 하는 일"을 짧게 설명 → AI 분야 심사에서 "예쁜 화면"과 구분되는 지점
  • 사운드 디자인 — 움직임 강도에 반응하는 사운드 하나만 제대로 넣어도 몰입감 평가에서 우위

9. 포토존 연출 아이디어

1. 클라이맥스 순간 셔터음+화면 플래시로 촬영 타이밍 암시
2. 바닥 반사 필름으로 "우주 안에 서 있는" 배경 연출
3. 완성 순간 QR로 개인정보 없는 별자리 이미지만 다운로드
4. 양손 벌리기 → 전체 파동, 역동적 포즈 자연 유도
5. 두 사람 근접 시 은하수 다리(연결선) — 커플·친구 사진 포인트
6. 부스 암막 처리로 역광 실루엣 사진 연출
7. "사진 찍지 마세요" 대신 "#ConstellationOfYou" 해시태그로 자발적 공유 유도
8. 전시 마지막 날, 하루 누적 별자리 타임랩스 재생 — 클로징 포토존
9. 정각마다 초신성처럼 폭발 후 재배열되는 이벤트 — 그룹 반응샷 유도
10. 부스 프레임을 우드/네온 액자로 꾸며 "움직이는 명화"처럼 연출

10. 확인 필요 (미정 사항)

  • 전시 공간의 실제 조도·암막 가능 여부 (웹캠 트래킹 정확도에 직결)
  • 구동 PC/노트북의 GPU 유무 (MoveNet Lightning vs Thunder 모델 선택에 영향)
  • 제스처 분류기를 Teachable Machine으로 직접 학습할지, 규칙 기반으로 갈지 — 일정에 따라 결정
  • 전시 종료 시 "거대한 별자리 아카이브" 결과물을 어떤 형태로 보존/전시할지 (인쇄물/영상/별도 모니터)
